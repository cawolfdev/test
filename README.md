# wildlife-bodybuilder

**Working branch:** `wildlife-bodybuilder-portrait`

Goal: one unchanged, recognizable human bodybuilder and pose, with camera viewpoints at 0°, 15°, 30°, 45°, 60°, 75°, 90°, 105°, and 120°. Every photographic view must be independently generated at native 1080 × 1920 or better. Crops and montages are not accepted. Preserve rejected generations and visibility diagnostics with checksums. Prefer Git history over duplicated, versioned copies of mutable documents.

**Current verified status:** Nine native-HD geometric diagnostic renders exist in the local working directory. The geometry is not anatomically fitted and fails 0°/60° silhouette validation. No new independent native-HD photographic view passes acceptance; the 0° and 60° source photographs are approximate visual references.

The current local working tree contains approximately 57 tracked paths and new rejected attempts. **This remote branch is a partial connector-side publication, not a verified complete binary mirror.** Do not rely on the branch for complete checkpoints or uploaded imagery until SHA verification proves it.

See `docs/OVERVIEW.md`, `docs/PLAN.md` and `reports/current.json`. Earlier project code in this branch comes from the existing wildlife prototype and is retained in Git history. Source of truth for artifacts remains the local working tree until full content sync can be verified.
